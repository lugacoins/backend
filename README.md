# LUGACOINS Backend

Backend oficial de LUGACOINS.

Este repositorio contiene el backend principal del sistema LUGACOINS, construido con Node.js, TypeScript y Express, siguiendo una arquitectura modular y escalable preparada para producción.

## Stack
- Node.js
- TypeScript
- Express
